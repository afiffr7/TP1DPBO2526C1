## Alur Program

    1. Program menggunakan perulangan while untuk mengatasi perubahan berkali-kali
    2. Program meminta untuk memilih menu CRUD
    3. User menginput nomor pilihan menu
    4. Program menjalankan pilihan menu, meminta input yang relevan dengan menu CRUD seperti meminta input kode target untuk mencari/mengedit/menghapus data.
